# React Hands-On 2 – User List using Fetch API

## 📌 Project Description

This project is a React application that retrieves and displays user information from an external API using React Hooks.

The application uses `useState()`, `useEffect()`, and the `fetch()` API to retrieve user data from the JSONPlaceholder API.

## 🎯 Objective

The main objective of this project is to understand:

- React Functional Components
- useState() Hook
- useEffect() Hook
- Fetch API
- API data handling
- Loading state
- Error handling
- Displaying dynamic user information

## 🚀 Features

- Fetches user information from an external API
- Displays User ID
- Displays Name
- Displays Username
- Displays Email
- Shows "Loading..." while data is being fetched
- Displays an error message if the API request fails
- Uses React Hooks for state and API handling

## 🌐 API Used

JSONPlaceholder Users API:

https://jsonplaceholder.typicode.com/users

## 🛠️ Technologies Used

- React.js
- JavaScript
- Vite
- HTML
- CSS
- Fetch API
